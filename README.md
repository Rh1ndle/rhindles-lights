# Rhindle's Lights

A browser tribute to the 2000 Windows screensaver **Voodoo Lights** by Sergio Duarte, rebuilt from observation only (no original code or assets).

Spinners, tubifex swarms, worms, meteors and trailers drift through a starfield with nebulas, sparkles and bloom. A three-stop era slider (Modern GPU / Voodoo 2 / Voodoo 1) recreates the look of mid-90s 3D hardware, and optional fly-by ships cruise past in the distance.

**Live:** https://rh1ndle.github.io/rhindles-lights/

Controls: `H` hides the panels, `F` fullscreen, `E` cycles the era.
